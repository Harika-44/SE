# Pharmacist feedback form (stakeholder satisfaction)

Give the pharmacist the generated SRS (`outputs/<run>/01_SRS.md`) and the open-issues list. Ask them to rate 1 (disagree) to 5 (agree):

| # | Statement | Score |
|---|---|---|
| 1 | The requirements describe how a dispensing workflow really works. | |
| 2 | Important requirements are not missing (list any below). | |
| 3 | The clarification questions are sensible and would save a meeting. | |
| 4 | The regulatory mappings point to the right rules (mark each wrong one). | |
| 5 | The risks and mitigations are realistic. | |
| 6 | I would trust this as a starting draft, with my review. | |

Also record: number of requirements the pharmacist edited, rejected, or added (human correction rate), and time spent reviewing.
